# RandFill
Overwrite files with cryptographically secure random data

```
Usage: randfill [OPTIONS] <TARGETS>...

Arguments:
  <TARGETS>...  

Options:
  -t, --threads <THREADS>  [default: 0]
  -v, --verbose            
      --urandom            
  -h, --help               Print help
  -V, --version            Print version
```

## Build

```shell
cargo build --release
```
